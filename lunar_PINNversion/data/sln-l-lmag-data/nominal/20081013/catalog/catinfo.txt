CATALOG DIRECTORY CONTENTS
---------------------------

The CATALOG subdirectory contains the completed catalog objects associated 
with the SELENE Level 2 Data.

The following files are found in this directory.

INSTHOST.CAT- Contains instrument host information.
MISSION.CAT - Contains mission information.
xxx_DS.CAT  - Contains dataset information of each instruments.
